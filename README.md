# ⚡ Total Optimization for SPT 4.1.x / 4.1.6
**The Ultimate All-in-One Performance, FPS & Memory Optimization Mod for Single Player Tarkov**

---

## 🇬🇧 Description (English)

**Total Optimization** is a comprehensive, deeply engineered performance enhancement mod for SPT (Escape from Tarkov). It is designed to boost frame rates, eliminate combat micro-stutters, and reduce system RAM usage.

Compatible out-of-the-box with **SAIN, ORBIT, Smoothie**.

### Features:
* **AI CPU Throttling:** Smart tick staggering for distant non-combat bots (>80m), saving 25-35% CPU. Instantly returns to 100% native tick rate in combat.
* **Full Body IK Culling:** Bypasses heavy bone IK solvers for distant bots (>45m).
* **RAM & VRAM Optimization:** Unloads uncompressed menu/ambient audio clips, clears asset caches post-load, and trims working set memory between raids.
* **De-Clutterer:** Removes tens of thousands of static puddles, cigarette butts, garbage piles, and debris across maps, dramatically reducing draw calls.
* **Scope Optimization (PiP):** Eliminates ADS frame drops by capping optic render texture resolution and view distance.
* **Muzzle Flash Stutter Fix:** Strips real-time dynamic shadow maps from gunfire.
* **In-Game F12 Configuration:** Full runtime control over every single optimization toggle.
